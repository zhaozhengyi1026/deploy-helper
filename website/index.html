交互式服务器部署工具

无需掌握 Linux 命令，
即可完成项目部署。

程序首先检查本地计算机环境，然后按照固定步骤采集部署信息。各步骤均支持跳过、重试和中断恢复，用户无需手动输入服务器命令。

查看安装步骤 查看交互示例

支持 Windows、macOS 和 Linux · 密码不写入本地配置文件

完整使用流程

部署过程由
七个连续阶段组成。

  1. 01

    检查本地计算机

    识别 Windows、macOS 或 Linux，并检查 Git 与 SSH。缺少工具时，程序会显示适用于当前系统的安装方法。

    约 1 分钟
  2. 02

    连接服务器

    填写服务器 IP、SSH 端口、用户名以及密码或密钥。用户还可选择配置 SSH 免密登录。

    约 2 分钟
  3. 03

    确认项目信息

    程序自动识别 Node.js、Python、静态网站或 Docker 项目，并要求用户确认项目名称、端口和启动方式。

    约 2 分钟
  4. 04

    填写项目配置

    如果项目包含 .env.example，程序将依次列出其中的环境变量，无需手动编辑配置文件。

    按项目而定
  5. 05

    安装服务器环境

    程序按需安装 Docker、Compose、Node.js、Python、Git 和 Nginx。每一项操作均在用户确认后执行。

    约 2–5 分钟
  6. 06

    传送并启动项目

    用户可选择上传当前目录，或由服务器通过 Git 拉取代码。随后程序会安装依赖、构建镜像并启动服务。

    约 2–10 分钟
  7. 07

    配置访问并执行检查

    仅在使用域名时配置 Nginx 和 HTTPS。最后检查应用进程状态以及 HTTP 访问结果。

    完成
